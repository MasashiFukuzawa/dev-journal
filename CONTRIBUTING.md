# Contributing

Open an issue before changing persisted data or compatibility contracts. Pull requests should be narrowly scoped, include regression tests, and pass the full verification set in `.agents/done.yml`.

Use temporary XDG directories in every runtime test. Do not include real issue text, identities, repository names, database files, logs, or credentials in reports or fixtures.

Public documentation is written in English. The agent skill remains primarily Japanese because its intended interaction language is Japanese.
