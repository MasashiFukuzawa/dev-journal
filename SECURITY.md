# Security policy

Please report vulnerabilities privately through GitHub's security advisory feature. Do not open a public issue containing a vulnerability, credential, private issue content, database, or log.

Only the latest release is supported. The server is a local tool without built-in authentication and is safe by default only on loopback. A non-loopback deployment requires an authenticated trusted network boundary and a strict Host allowlist.

The journal database contains source issue bodies, comments, analysis, and chat messages. Treat it and its backups as confidential user data.
